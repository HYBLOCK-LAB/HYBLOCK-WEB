# 로컬 UI 검수 보고서

## 검수 환경

- 날짜: 2026-07-28
- 대상: 활동 앨범 MVP 기준 브랜치
- 화면: 데스크톱 1280px, 모바일 390px
- 방법: 로컬 Next.js 개발 서버, 실제 브라우저 DOM·화면 확인

## 확인된 문제와 조치

| 구분 | 확인 내용 | 조치 |
| --- | --- | --- |
| 콘텐츠 구조 | 사진 28장이 개별 카드로 보여 동일 행사명이 반복됨 | 사진을 8개 활동 앨범으로 묶고 목록·상세 분리 |
| 시각 위계 | 큰 연도 숫자, 큰 그림자, 둥근 카드가 반복돼 템플릿 인상이 강함 | 연도 크기 축소, 12px 카드, 1px 경계, 1px hover로 정리 |
| 모바일 필터 | 긴 필터 마지막 항목이 잘림 | 모바일은 전체 너비 `select`, 태블릿 이상은 줄바꿈 버튼 사용 |
| 모바일 탐색 | 공개 메뉴가 숨겨져 공지·활동으로 이동할 수 없음 | 메뉴 버튼과 모바일 내비게이션 추가 |
| 문자 깨짐 | Font Awesome CDN 실패 시 푸터 아이콘이 전용 글리프로 표시됨 | 로컬 React 아이콘으로 교체하고 CDN 의존 제거 |
| 링크 오류 | 헤더와 홈의 `/apply`가 404 응답 | 임시 지원 안내 페이지 추가 |
| 임시 페이지 | 그라데이션·블러·큰 그림자가 과해 본문보다 장식이 강함 | 평면 배경, 구분선, 단일 CTA 중심으로 단순화 |

## 검수 기준

- 문서 인코딩과 화면 텍스트에서 `�` 대체 문자가 없어야 한다.
- 페이지 전체 가로 스크롤이 없어야 한다.
- 모바일에서 주요 메뉴와 필터를 사용할 수 있어야 한다.
- 푸터 외부 링크에 읽을 수 있는 접근성 이름이 있어야 한다.
- 활동 목록에는 사진 수가 아니라 앨범 수가 표시돼야 한다.
- 목록 카드에서 상세 페이지로 이동할 수 있어야 한다.
- 상세 페이지는 잘못된 slug를 404로 처리해야 한다.
