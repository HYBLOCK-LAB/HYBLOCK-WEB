## 2. 공개 화면

### 목록 `/activities`

- 페이지 설명
- 모바일 `select`, 태블릿 이상 버튼형 카테고리 필터
- 연도 제목 아래 월별 앨범 목록
- 앨범 카드: 대표 사진, 분류, 날짜, 제목, 설명, 사진 수
- 날짜 미정 앨범 전용 구역
- 빈 결과 안내

### 상세 `/activities/[slug]`

- 목록으로 돌아가기
- 분류, 날짜, 사진 수
- 제목과 설명
- 대표 사진
- 전체 사진 그리드
- 존재하지 않는 slug의 404 처리

라이트박스는 1차 범위에 넣지 않는다. 목록과 상세의 정보 구조, 이미지 성능, 키보드 접근을 먼저 안정화한다.

## 3. 관리자 화면

새 경로 `/admin/activity-albums`에서 다음을 제공한다.

- 앨범 생성·수정
- 한국어·영어 제목과 설명
- 분류와 활동 날짜
- 다중 이미지 업로드와 진행 상태
- 사진 순서 변경
- 대표 사진 선택
- 초안·게시 상태 전환

기존 `/admin/activities`는 출석 세션 관리이므로 변경하지 않는다.

## 4. 데이터 모델

### `activity_album`

| 필드 | 형식 | 설명 |
| --- | --- | --- |
| `id` | bigint | 내부 식별자 |
| `slug` | text unique | 공개 상세 URL |
| `title_ko`, `title_en` | text | 다국어 제목 |
| `description_ko`, `description_en` | text | 다국어 설명 |
| `category` | text | 허용된 활동 분류 |
| `activity_date` | date nullable | 연·월 그룹 기준 |
| `cover_image_id` | bigint nullable | 대표 사진 |
| `status` | draft/published | 공개 상태 |
| `created_by` | member FK | 생성 관리자 |
| `created_at`, `updated_at` | timestamptz | 감사 정보 |

### `activity_album_image`

| 필드 | 형식 | 설명 |
| --- | --- | --- |
| `id` | bigint | 이미지 식별자 |
| `album_id` | activity_album FK | 소속 앨범 |
| `storage_path` | text unique | Storage 경로 |
| `alt_ko`, `alt_en` | text | 대체 텍스트 |
| `sort_order` | integer | 상세 표시 순서 |
| `uploaded_by` | member FK | 업로드 관리자 |
| `created_at` | timestamptz | 업로드 시각 |

대표 사진은 같은 앨범에 속한 이미지만 지정할 수 있도록 서버에서 검증한다.

## 5. 이전 절차

1. 운영진이 8개 앨범의 날짜, 설명, 대표 사진을 확인한다.
2. 공개 가능한 사진만 선별한다.
3. 원본 이미지를 웹용 크기와 용량으로 변환한다.
4. Storage 업로드 후 앨범·사진 레코드를 생성한다.
5. 정적 데이터와 DB 결과를 비교한다.
6. 공개 페이지를 DB 조회로 전환한다.
7. 전환 검수 후 정적 데이터를 별도 PR에서 제거한다.

## 6. 완료 조건

- 8개 활동을 연도·월별 앨범으로 탐색할 수 있다.
- 카테고리 필터 결과와 앨범 수가 일치한다.
- 앨범 상세를 새로고침해도 정상 표시된다.
- 날짜 미정 기록은 별도 구역에만 나타난다.
- 390px에서 필터와 카드가 잘리지 않는다.
- 대표 사진과 상세 사진에 내용 기반 대체 텍스트가 있다.
- 이미지 실패, 빈 앨범, 비공개 앨범, 잘못된 slug를 처리한다.
- 홈 미리보기에서도 동일 활동 사진이 반복되지 않는다.
